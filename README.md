# Mizan Qist Limited — website

Marketing site for Mizan Qist Limited (RC 9569963): **Labs** (products), **Studio** (creative and technology services) and **Private Office** (private advisory). Built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4 and Framer Motion.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build (also type-checks)
npm run lint
```

Deploy to Vercel with zero configuration: import the repo, keep the defaults, deploy. Set `url` in `src/content/site.ts` to the live domain so canonical URLs, Open Graph tags, `sitemap.xml` and `robots.txt` point at it.

## Where to edit content

Everything editable lives in `src/content/` as typed TypeScript. Components only render what is there.

| File | What it controls |
| --- | --- |
| `site.ts` | Company name, RC number, email, phones, WhatsApp link, offices, social links, site URL, default description |
| `navigation.ts` | Header links, header call-to-action, footer link groups |
| `divisions.ts` | The three division cards (name, pitch, image) used on Home and About |
| `home.ts` | Home hero, mission, "how we work" points, stats strip, closing call-to-action |
| `labs.ts` | Labs hero, vision copy, eight focus areas, **products in development** (name, category, status, description, optional link), partner CTA |
| `studio.ts` | Studio hero, service categories and services, industries, personal & celebrations, process steps, partner programme, form options (service types, budgets, timelines) |
| `portfolio.ts` | Portfolio items for `/studio/work` and the case-study pages. Each item: slug, title, client, category, tags, year, summary, cover, gallery, challenge, approach, outcome, services, `featured` |
| `private-office.ts` | Private Office hero, six services, approach points, consultation copy and form options |
| `about.ts` | Story, mission, values, division structure copy, **team members** (first card is the Managing Director) |
| `testimonials.ts` | Quotes shown on Home and Studio (filtered by division) |
| `legal.ts` | Privacy policy and Terms of use sections |

Page shells live in `src/app/<route>/page.tsx`; sections and cards in `src/components/`.

## Rebrand in one place

`src/styles/theme.css` holds every design token: brand palette, division accents, fonts, type scale, radii, spacing, shadows, and the semantic light/dark tokens (`bg`, `fg`, `muted`, `line`, `card`, `surface`, `accent`). Tailwind v4 turns each token into utilities, so `bg-charcoal-800`, `text-accent`, `rounded-xl`, `font-display` all come from that file.

- **Colours**: edit the `--color-*` values. `--accent` changes per division through `[data-division="labs|studio|office"]` on each page wrapper.
- **Fonts**: swap the Google fonts in `src/app/layout.tsx` (currently Fraunces for display, Archivo for body) and the `--font-display` / `--font-sans` tokens.
- **Dark mode**: `next-themes` toggles the `.dark` class; the Private Office page is always dark via its own `.dark` wrapper.

## Swap images

- **Logo**: files in `public/brand/` — `logo-light.png` (charcoal, for light backgrounds), `logo-dark.png` (white, for dark backgrounds), `mark-light.png` / `mark-dark.png` (the circular MQ mark), `logo-original.png`. Replace them keeping the same names, or edit `src/components/ui/Logo.tsx`. The favicon is `src/app/icon.png` and `src/app/apple-icon.png`; the Open Graph card is generated by `src/app/opengraph-image.tsx` from `logo-dark.png`.
- **Photos**: every image URL in `src/content/` is an Unsplash **placeholder**. Put your files in `public/` (for example `public/work/<slug>/cover.jpg`) and change the string to `/work/<slug>/cover.jpg`. Once no Unsplash URLs remain you can delete the `remotePatterns` block in `next.config.ts`.
- **Team photos**: `about.ts` → `team[].image`.

## Forms

Three forms share one component, `src/components/forms/EnquiryForm.tsx`: Studio project enquiry, Private Office consultation, and general Contact. Validation rules live in `src/lib/enquiry.ts` (zod) and run on the client and again in `src/app/api/enquiry/route.ts`. The API route currently logs the payload to the server console.

## Accessibility and performance notes

Semantic landmarks, skip link, keyboard-accessible menu (native `<dialog>`), visible focus rings, `aria-pressed` filters, live regions on forms. Animations are opt-out via `prefers-reduced-motion` (Framer Motion `reducedMotion="user"` plus a CSS fallback). Images use `next/image`; fonts use `next/font`. Only the header, theme toggle, forms, portfolio filter and reveal animations ship client JavaScript.
